A massive dataset of expert trajectories in over 10M unique tasks

Introduction

Current generalist agents are inevitably pre-trained on massive datasets spanning a wide range of tasks, and then perhaps fine-tuned online using RL. Kinetix allows the studying of large-scale, generalist agents in an online setting. Here we are releasing a large offline dataset of expert trajectories from over 10M unique environments. This dataset was generated by training per-level expert policies using PPO, and then collecting some trajectories from each policy.

Dataset

We have a few different available datasets. These are split by environment size (how many entities are there in a scene) and whether or not the data is grouped according to trajectories or transitions.

Dataset Collection Process

We train specialist RL agents per level for a fixed number of timesteps and then collect a single trajectory per level to save to the dataset. Since not all environments are solvable, these experts do not always succeed in the task. For the released dataset, we select only the optimal trajectories from solvable tasks.

Dataset Details

We have 5 different datasets, corresponding to different environment sizes (s, m, l), and how long we train each expert policy for, either 1M or 10M timesteps.

Unique Levels is the number of distinct levels for which trajectories were collected; Transitions is the total number of individual environment steps across all trajectories.

Dynamic Rendering

One benefit of Kinetix is that we can specify the rendering function dynamically at runtime, meaning that the same data can be used to train symbolic or pixel-based agents.

Usage

We have updated the Kinetix repository to include utilities to read the data, and train agents on it.

Conclusion

If you are interested in training using large-scale behaviour cloning, or if you wanted to train a video or world model, now you can easily do so.
